# Azure Brain

Cerebro técnico persistente sobre Microsoft Azure, en Markdown compatible con Obsidian. Acompaña el aprendizaje de Azure desde cero, la preparación de certificaciones, laboratorios, arquitecturas, buenas prácticas y troubleshooting — pensado para crecer durante años.

Basado en el patrón [LLM Wiki](karpathy.txt), adaptado a Azure. Las reglas de mantenimiento (qué va en cada carpeta, frontmatter, convenciones de enlace, flujo de ingesta) están en [CLAUDE.md](CLAUDE.md).

## Estructura

- **`raw/`** — fuentes originales inmutables (docs oficiales, repos clonados, cursos).
- **`knowledge/`** — conocimiento consolidado, un concepto por página.
- **`certifications/`** — guía de estudio por certificación (`INDEX.md` + notas/labs/ejemplos).
- **`examples/`** — ejemplos de código reutilizables (CLI, Bicep, Terraform, PowerShell, Python, C#).
- **`assets/`** — imágenes y diagramas.
- **[`INDEX.md`](INDEX.md)** — catálogo de todo el contenido.
- **[`log.md`](log.md)** — registro cronológico de la evolución del repositorio.
