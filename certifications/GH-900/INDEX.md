# GH-900: GitHub Foundations

## Descripción

Certificación de entrada sobre GitHub: Git, repositorios, herramientas de colaboración, gestión de proyectos y prácticas de desarrollo modernas. Dirigida tanto a no-desarrolladores como a desarrolladores.

## Objetivos

Conocimientos fundamentales de GitHub y sus características principales.

## Habilidades medidas

*Vigente desde enero de 2026 según la guía oficial (examen actualizado significativamente ese mes) — verificar antes de programar el examen.*

| Área | Peso |
|---|---|
| Conceptos básicos de Git y GitHub | 25-30% |
| Trabajo con repositorios de GitHub | 10-15% |
| Colaboración mediante GitHub | 10-15% |
| Aplicar prácticas de desarrollo modernas | 10-15% |
| Administración de proyectos con GitHub | 5-10% |
| Privacidad, seguridad y administración | 10-15% |
| Comunidad de GitHub | 5-10% |

## Módulos

### Conceptos básicos de Git y GitHub (25-30%)

- [ ] **Control de versiones**: propósito y ventajas, diferencia Git vs GitHub, conceptos clave (repos, commits, ramas)
- [ ] **Trabajar con GitHub**: cuentas/organizaciones/enterprise, GitHub flow, Markdown en issues/PRs, GitHub Desktop y Mobile

### Trabajo con repositorios (10-15%)

- [ ] Estructura y archivos clave (README, LICENSE, CONTRIBUTING, CODEOWNERS, SECURITY), plantillas y ramas, gestión de archivos, insights/stars/dependency info, buenas prácticas de mantenimiento

### Colaboración mediante GitHub (10-15%)

- [ ] Issues, pull requests y discussions; vincular PRs a issues, plantillas/filtros/asignaciones; notificaciones; Gists, Wikis, GitHub Pages

### Prácticas de desarrollo modernas (10-15%)

- [ ] GitHub Actions (propósito y funcionalidades); GitHub Copilot (agentes, modo agente, múltiples modelos) y diferencias entre planes (Individual/Business/Enterprise); GitHub Codespaces y dev containers; github.dev vs Codespaces

### Administración de proyectos (5-10%)

- [ ] GitHub Projects (vistas), etiquetas, hitos, flujos de trabajo, respuestas guardadas y asignados, seguimiento de progreso/productividad

### Privacidad, seguridad y administración (10-15%)

- [ ] 2FA y passkeys, permisos y roles de acceso, Enterprise Managed Users (EMU), políticas de Copilot a nivel de organización, visibilidad de repos y branch protection rules, gestión de settings/equipos/roles

### Comunidad de GitHub (5-10%)

- [ ] GitHub Sponsors y ventajas del open source, cómo GitHub impulsa proyectos open source, seguir usuarios/organizaciones, GitHub Marketplace, InnerSource, forks/plantillas/template repositories
