# Azure Cloud Shell

> Página pendiente de contenido completo. Azure Cloud Shell es un shell interactivo, autenticado y accesible desde el navegador para administrar recursos de Azure, con opción de Bash o PowerShell. Stub creado al iniciar el estudio del módulo [Introduction to Azure Cloud Shell](https://learn.microsoft.com/es-es/training/modules/intro-to-azure-cloud-shell/) (ruta de prerrequisitos de AZ-104, Bloque 0).
>
> Pendiente de cubrir: Bash vs PowerShell y conmutación · persistencia de archivos (`clouddrive`/`$HOME` en un File Share de una storage account) · autenticación automática como usuario de Entra ID · carácter efímero de la sesión y requisito de storage account · integración con Azure CLI, Az PowerShell y herramientas (`az`, `kubectl`, `terraform`).
>
