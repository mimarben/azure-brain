# Laboratorios — AI-200

Índice de laboratorios prácticos disponibles para AI-200. No duplica contenido ya detallado en otras páginas — enlaza a él.

## Microsoft Learn (módulos con ejercicio integrado)

Los 24 módulos oficiales de las 9 rutas de aprendizaje de AI-200 incluyen un sandbox/ejercicio práctico embebido en Microsoft Learn. Detalle completo, con checkboxes de progreso y enlaces directos a cada módulo, en [notes/AI-200/roadmap.md](../../notes/AI-200/roadmap.md).

## Plantillas desplegables (quickstarts)

Plantillas ARM/Bicep oficiales de `Azure/azure-quickstart-templates`, listas para `az deployment group create`. Índice completo en [examples/bicep/README.md](../../examples/bicep/README.md) — incluye AI Agent Service, Cognitive Services, AI Search, Cosmos DB, PostgreSQL, Key Vault, AKS, ACR, Health Data AI Services.

## Hands-on labs / Azure Samples (no clonados todavía)

Ningún repo de hands-on labs de Azure-Samples está clonado en `raw/github/` todavía. Candidatos identificados en [notes/AI-200/missing-documentation.md](../../notes/AI-200/missing-documentation.md):

- `Azure-Samples/azureai-samples` — notebooks y hands-on labs oficiales de Azure AI Foundry/OpenAI.
- `Azure-Samples/azure-search-openai-demo` — laboratorio end-to-end de patrón RAG (Azure OpenAI + AI Search), el más representativo del Bloque 2 de la skills outline.

## Tutoriales oficiales sin módulo Learn dedicado

Pendiente de identificar durante el estudio — añadir aquí cuando el usuario encuentre tutoriales de Microsoft Learn (fuera de las 9 rutas oficiales) que merezcan la pena, p. ej. tutoriales de Azure AI Foundry portal o de Document Intelligence Studio.
