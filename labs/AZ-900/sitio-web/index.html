Características

Sencilla, estática y rápida.

Estática y rápida

Solo HTML, CSS y JS. Sin backend ni runtime: el contenido se sirve tal cual desde la infraestructura de Azure.

Bootstrap 5 por CDN

Componentes y utilidades listos para usar, cargados desde CDN. Sin herramientas de build ni dependencias locales.

Responsive

Grid y breakpoints de Bootstrap: la página se adapta a móvil, tablet y escritorio sin esfuerzo extra.

Acerca de este laboratorio

Página de práctica para la certificación AZ-900 Azure Fundamentals. Sirve para ver el ciclo completo de una web estática en Azure: actualizar el contenido, volver a desplegar y comprobar el resultado en el navegador.
